# 📅 Booking System — Appointment Management Application

A **Flutter-based appointment management application** designed to simplify scheduling and managing appointments with reliable state management and offline data persistence.

## ✨ Features

* 📅 **Appointment Scheduling** — Create and manage new appointments.
* ✏️ **Edit Appointments** — Update existing booking details.
* ❌ **Cancellation** — Cancel appointments when needed.
* 📋 **Booking History** — View and manage previous appointments.
* 🕐 **Availability Management** — Manage available appointment slots.
* 💾 **Offline Persistence** — Store booking data locally using Hive.
* 🔄 **State Management** — Handle loading, success, validation, and error states using Cubit.
* 📱 **Flutter UI** — Responsive and user-friendly interface.


## 🧠 Technical Highlights

* Used **Cubit** to provide predictable and maintainable application state management.
* Implemented **Hive** for fast local storage and offline access to booking information.
* Structured the application around clear appointment management flows, including creation, editing, cancellation, and history.
* Implemented proper **loading, validation, success, and error states** to provide reliable user feedback.
